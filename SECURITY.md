# Security And Privacy

## Supported Branch

Security and privacy fixes are accepted for the default branch after public release.

## Reporting

Please report suspected exposure of survey exports, response identifiers, free-text responses, or other restricted material privately to the repository maintainer rather than opening a public issue.

## Data Boundary

The raw Qualtrics workbook and any respondent-level exports are restricted. They should remain in local ignored paths such as `data/private/` and must not be committed to the public repository.
